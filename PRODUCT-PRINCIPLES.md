# Node Builder — Product Principles

## The Mission
Help non-technical people set up a Lightchain AI worker node, and support them after.

## The Filter
Before building any feature, ask one question:

> **"Does this help a non-technical person set up their node, or support them after?"**

If the answer is no — don't build it.

## What that means in practice
- Setup guidance: yes
- Troubleshooting help: yes
- Plain-English explanations: yes
- AI assistant for questions: yes
- Health checks with fix tips: yes
- Live dashboard / node management: no (workers.lightchain.ai does this)
- Wallet connect: no (not needed for setup)
- Advanced analytics: no (not the goal)

## Who we're building for
A person who has the hardware and the LCAI but has never touched a terminal before. They should be able to follow this wizard, set up their node, and know what to do when something goes wrong — without needing to ask anyone for help.

## The edge
LightNode automates setup so you never understand what you built.
Node Builder teaches setup so you can actually run and fix your own node.
