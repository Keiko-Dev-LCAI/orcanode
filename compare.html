One button. Scans Docker, Ollama, VPN, config, logs, and on-chain status on this computer. Shows only what doesn't match a verified earning mainnet node — plus how to fix each item.

Before you compare

The compare tool reads your local machine. Start the OrcaNode server on the same computer as your worker:

python3 ~/Desktop/orcanode/orcanode-server.py
  1. Run the command above in a terminal (leave it open).
  2. Open this page at http://localhost:8185/compare — or stay here if you already did.
  3. Click Compare Now.
